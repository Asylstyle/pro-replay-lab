# Способности мидеров на 7.41f

В матчапе можно открыть карточки своего героя и соперника. Справочник охватывает **127 героев и 667 способностей и связанных кнопок**, в том числе Invoker, Meepo и героев с двумя стойками. Карточки показывают значения по рангам, расход ресурсов, перезарядку и условия, которые стоит искать в повторе. Для обычной способности, доступной с 1/3/5/7 уровня, третий ранг означает возможность вложить очко на пятом уровне. Для совета в конкретном кадре нужен фактический ранг. [Список героев Valve](https://www.dota2.com/datafeed/herolist?language=russian)

Для **61 способности у 52 героев** отдельно описаны один исходный компонент урона, область действия и время до попадания. Большая цифра на верхнем ранге сама по себе ничего не говорит о добивании в конкретной игре. Важны здоровье и защита крипа, видимость, дистанция, доступность каста и то, успеет ли сработать способность до следующего удара по крипу. Бонусы от случайных эффектов, дополнительных атак или будущих тиков требуют отдельной проверки.

| Герой | Что проверить у спорного крипа |
| --- | --- |
| Shadow Fiend | У трёх койлов центры лежат на 200, 450 и 700 единицах перед героем, радиус каждого 250. Базовый урон составляет 85/150/215/280. Число душ и предыдущие попадания могут его увеличить. Для совета важны направление взгляда и готовность нужной кнопки. |
| Storm Spirit | При применении Static Remnant на себя копия материализуется через 0,75 с. Радиус срабатывания 235, радиус урона 300. Для применения с перемещением нужно проследить путь копии и найти первый юнит, который вызовет взрыв. |
| Puck | Альтернативное применение направляет Illusory Orb прямо. Карточка оценивает начальное попадание на этой траектории. Векторное применение позволяет искривить путь, а при длительном контакте сфера наносит дополнительный урон. |
| Outworld Destroyer | Astral Imprisonment наносит урон при выходе через 1,75/2,5/3,25/4 с. Для Arcane Orb нужно определить ману **после** расхода и время попадания усиленной атаки. |
| Ember Spirit | Searing Chains выбирает две цели в области, у Sleight of Fist отдельный бонус против героев, а у Flame Guard важно время контакта до исчезновения щита. Для этих трёх способностей карточка показывает параметры и условия. |
| Invoker | У Sun Strike урон зависит от Exort и делится между врагами в области. Для Tornado нужны Wex для урона и Quas для времени подъёма. Список кнопок в книге заклинаний шире доступных в конкретном кадре. |
| Meepo | На этом патче первое очко Divided We Stand доступно с третьего уровня. Для Poof сравни положения и доступность каждого клона, точки отправления и прибытия. |

## Обновление снимка

Из корня проекта выполните `py scripts/build_mid_spells.py`. Сборщик проверяет действующий патч до и после загрузки профилей. Параметр `--from-dir ПАПКА` принимает уже сохранённые русскоязычные профили Valve в файлах `hero_ID.json` с объектом героя внутри. В обоих режимах список героев и календарь запрашиваются у Valve. При смене патча проверьте выбранные компоненты урона, условия попадания и правила прокачки. Игровой отчёт использует готовый снимок из проекта.

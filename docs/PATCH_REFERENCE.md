# Планки экономики на патче 7.41f

Ориентиры показывают, как фармят игроки в проверенных лобби высокого рейтинга и на профессиональных картах. Пользователь вводит ID собственной игры и выбирает героя. Отчёт сравнивает его показатели на 10:00 и 20:00 с каждой группой. Порог 7 300 относится к источникам для сравнения. Посмотреть собственную игру может игрок любого рейтинга.

| Источник | Как подтверждаем карту | Матчей | Выступлений |
| --- | --- | ---: | ---: |
| Рейтинговый All Pick | OpenDota Live сообщил числовой средний MMR лобби ≥ 7 300. В итоговой карточке совпали ID, режим и пятёрки героев | 30 | 300 |
| Про-матчи | Турнирное лобби и лига уровня professional или premium по OpenDota | 307 | 3 070 |

В этой выборке средний рейтинг принятых лобби лежит между **7 685 и 8 304**. В одном снимке Live нашлось 47 подходящих кандидатов с полным известным составом. Для 30 нашлись полные снимки экономики, 12 ожидали итоговой карточки, у трёх недоставало данных, ещё две игры закончились до 20:00. Число таких лобби зависит от того, какие карты OpenDota показывает во время наблюдения. Формулу расчёта опубликованного `average_mmr` и число учтённых индивидуальных рейтингов источник не раскрывает. [OpenDota Live](https://api.opendota.com/api/live) · [Журнал отбора](../examples/patch-reference-ranked-manifest.json)

Про-выборка объединяет 227 подходящих сохранённых карт и 80 дополнительно найденных в OpenDota. Она охватывает 12 лиг. Все карты обеих групп стартовали на 7.41f по календарю Valve. Время сверки и даты начала сохранены. [Журнал про-матчей](../examples/patch-reference-pro-manifest.json) · [Календарь Valve](https://www.dota2.com/datafeed/patchnoteslist?language=english)

В таблице тренера приведены арифметические средние отдельно для каждой позиции и источника. Отчёт использует позицию игрока из разбора или ручного выбора. Если позиция неизвестна, он помечает сравнение по месту среди союзников по золоту на 10:00. Исторические позиции в корпусе оценены OpenDota. Для каждого среднего показан размер группы. Показатель ML рядом учитывает стартовые условия игрока и обучен на объединённом корпусе, в котором преобладают про-игры. Если рассматриваемая карта входит в итоговую модель, в отчёте есть пометка.

## Проверка прогноза до итогового обучения

Пять вариантов сравнили на трёх последовательных временных разбиениях внутри 269 ранних про-карт. Варианты включали медианный прирост по месту в команде, прежний Ridge и Ridge с дополнительными признаками и тремя значениями регуляризации. Никто из десяти игроков проверочной карты не попадал в обучение на этом разбиении. Победил Ridge с дополнительными признаками и коэффициентом 1.

Затем зафиксированный вариант сравнили с ранее опубликованным прогнозом клиента на 68 более поздних картах. Ниже средняя абсолютная ошибка прогноза к 20:00. Меньшее значение лучше.

| Отложенные карты | Добивания, прежний → новый | Золото, прежний → новый | Опыт, прежний → новый |
| --- | ---: | ---: | ---: |
| 38 про-матчей | 13,50 → 13,05 | 617 → 599 | 935 → 907 |
| 30 рейтинговых 7 300+ | 17,75 → 16,41 | 760 → 773 | 1 203 → 1 226 |
| Все 68 карт | 15,38 → 14,53 | 680 → 676 | 1 053 → 1 048 |

На общей выборке парный 95%-й интервал разницы по добиваниям составил от −1,51 до −0,23 крипа. Интервалы по золоту и опыту включают ноль. На рейтинговых картах ошибки по этим двум показателям выросли. Из 68 карт 13 уже фигурировали в предыдущих исследованиях приложения. Отдельная проверка на остальных 55 дала снижение ошибки добиваний с 15,69 до 14,85.

Все 30 рейтинговых игр были получены из недавнего снимка Live. В хронологической проверке они целиком оказались в поздней части. Проверка на них измеряет перенос с про-сцены. После неё итоговую модель обучили на всех 337 картах. Для независимой оценки этой итоговой версии нужны следующие завершённые лобби. [Результаты и интервалы](../examples/patch-reference-comparison.json) · [Итоговая модель и разбиения](../examples/patch-reference-model.json)

## Обновление и воспроизведение

После публикации итоговую модель проверили ещё на 23 новых рейтинговых матчах со средним MMR 7 300+. [Свежая проверка по золоту и опыту](FRESH_RANKED_EVALUATION.md)

Запускай из корня репозитория в окружении Python 3.14 с зависимостями из `requirements-ml.txt`.

```powershell
# Обновить выборки и активные планки с использованием OpenDota и Valve
.\.venv\Scripts\python scripts/refresh_patch_reference.py

# Офлайн повторить опубликованный эксперимент строго на его входных данных
.\.venv\Scripts\python -m pro_replay train-reference --replays examples/patch-reference-pro.json.gz examples/patch-reference-ranked.json.gz --frozen-policy examples/patch-reference-policy.json --out data/reproduced-reference.json
.\.venv\Scripts\python scripts/compare_patch_reference.py --out data/patch-reference-comparison.json

# Использовать явно выбранную модель планок
py -m pro_replay school --reference data/reproduced-reference.json
```

Сборщик накапливает наблюдения Live между запусками. Для матча без подтверждённого числового среднего рейтинга нужны новые данные источника. Медаль Immortal и отдельные рейтинги игроков не используются для восстановления числа. При смене патча ориентиры строятся заново. Если матчей пока мало для временной проверки, тренер уже может показать средние и число наблюдений. Старую модель он применяет только к играм её патча.

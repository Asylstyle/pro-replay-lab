# Планки экономики на патче 7.41f

После выбора матча и героя тренер определяет группу по типу игры. Для рейтингового All Pick он показывает средние и прогноз по пабам с подтверждённым средним MMR от 7 300. Для профессиональной карты он использует турнирные игры. Собственный рейтинг клиента может быть любым. Если режим игры или уровень лиги установить не удалось, в отчёте указана причина, по которой сравнение недоступно.

| Источник | Как подтверждаем карту | Матчей | Выступлений |
| --- | --- | ---: | ---: |
| Рейтинговый All Pick | OpenDota Live сообщил числовой средний MMR лобби ≥ 7 300. В итоговой карточке совпали ID, режим и пятёрки героев | 53 | 530 |
| Про-матчи | Турнирное лобби и лига уровня professional или premium по OpenDota | 307 | 3 070 |

Для 53 отобранных пабов OpenDota сообщил средний рейтинг от **7 685 до 8 327**. Все матчи взяты из сохранённых наблюдений Live с полными составами и итоговыми показателями на 20:00. Размер выборки ограничен временем наблюдения и покрытием источника. [Журнал отбора пабов](../examples/fresh-ranked-2026-11-17/manifest.json) · [История сбора](../examples/fresh-ranked-2026-11-17/collection.json)

Про-выборка объединяет 227 подходящих сохранённых карт и 80 дополнительно найденных в OpenDota. Она охватывает 12 лиг. Все карты обеих групп стартовали на 7.41f по календарю Valve. Время сверки и даты начала сохранены. [Журнал про-матчей](../examples/patch-reference-pro-manifest.json) · [Календарь Valve](https://www.dota2.com/datafeed/patchnoteslist?language=english)

Отчёт показывает арифметические средние по позиции и число выступлений в выбранной группе. Позицию клиента можно указать вручную. Если она неизвестна, тренер сравнивает игроков по месту среди союзников по золоту на 10:00. Позиции в корпусе оценены OpenDota. Для карты из итоговой обучающей выборки в отчёте есть пометка.

## Проверка двух моделей

Внутри каждой группы на трёх последовательных временных разбиениях сравнили медианный прирост ресурсов по месту в команде на 10:00, базовую Ridge-регрессию и Ridge с дополнительными признаками при трёх коэффициентах регуляризации. Для проверки оставили более поздние матчи той же группы. Все десять игроков каждой карты попадают в одну часть. Матчи, которые продолжались в момент начала проверки, исключены из обучения на этом разбиении.

| Группа | Ранние карты для выбора модели | Пересекли границу проверки | Поздние карты для оценки | Выбранная модель |
| --- | ---: | ---: | ---: | --- |
| Рейтинговый All Pick 7 300+ | 35 | 7 | 11 | Базовая Ridge |
| Про-матчи | 244 | 1 | 62 | Ridge с дополнительными признаками, коэффициент 1 |

Ниже средняя абсолютная ошибка прогноза к 20:00 по данным, доступным на 10:00. В каждой ячейке приведены результаты простой медианы и выбранной модели. Меньшее значение лучше.

| Поздние карты | Добивания, медиана → модель | Золото, медиана → модель | Опыт, медиана → модель |
| --- | ---: | ---: | ---: |
| 11 пабов 7 300+ | 20,07 → 16,00 | 994 → 857 | 1 336 → 1 176 |

После проверки выбранные модели обучены на всех 53 пабах и 307 про-матчах соответственно. Проверка ретроспективная. Одиннадцать рейтинговых карт дают предварительную оценку ошибки на 7.41f. Точность на следующей партии пабов пока неизвестна. [Разбиения, модели и ошибки](../examples/patch-cohort-model.json)

## История объединённой модели

В предыдущем эксперименте на 269 ранних про-картах выбрали Ridge с дополнительными признаками. Эту версию сравнили с тогдашней моделью тренера на 68 более поздних картах. Ниже результаты того сравнения.

| Отложенные карты | Добивания, прежний → новый | Золото, прежний → новый | Опыт, прежний → новый |
| --- | ---: | ---: | ---: |
| 38 про-матчей | 13,50 → 13,05 | 617 → 599 | 935 → 907 |
| 30 рейтинговых 7 300+ | 17,75 → 16,41 | 760 → 773 | 1 203 → 1 226 |
| Все 68 карт | 15,38 → 14,53 | 680 → 676 | 1 053 → 1 048 |

На общей выборке парный 95%-й интервал разницы по добиваниям составил от −1,51 до −0,23 крипа. Интервалы по золоту и опыту включают ноль. На рейтинговых картах ошибки по этим двум показателям выросли. Из 68 карт 13 уже фигурировали в предыдущих исследованиях приложения. Отдельная проверка на остальных 55 дала снижение ошибки добиваний с 15,69 до 14,85.

Все 30 рейтинговых игр той версии целиком оказались в поздней части, поэтому проверка на них измеряла перенос с про-сцены. После неё общую модель обучили на 337 картах и проверили ещё на 23 рейтинговых матчах. Все 53 паба теперь входят в корпус для отдельной рейтинговой модели. Исторический результат на 23 картах относится к предыдущей версии. ## Обновление и воспроизведение

Запускай из корня репозитория в окружении Python 3.14 с зависимостями из `requirements-ml.txt`.

```powershell
# Обучить отдельного кандидата по накопленному снимку 18 ноября без сети
.\.venv\Scripts\python -m pro_replay train-reference --frozen-policy examples/ranked-collection-2026-11-18/manifest.json --out data/next-reference.json

# Повторить проверку опубликованных весов на добавленных пабах без обучения
.\.venv\Scripts\python scripts/score_ranked_collection.py --capture examples/ranked-collection-2026-11-18 --out data/ranked-collection-score.json

# Обновить выборки и активные планки с использованием OpenDota и Valve
.\.venv\Scripts\python scripts/refresh_patch_reference.py

# Офлайн пересобрать обе опубликованные модели из проверенных снимков
.\.venv\Scripts\python scripts/refresh_patch_reference.py --rebuild-packaged

# Повторить историческое сравнение по сохранённой объединённой модели
.\.venv\Scripts\python scripts/compare_patch_reference.py --out data/patch-reference-comparison.json

# Использовать опубликованные раздельные ориентиры, даже если есть локальная модель
py -m pro_replay school --reference examples/patch-cohort-model.json
```

Для офлайн-обучения первая команда читает завершённые пабы из соседнего `matches.json.gz` и опубликованные про-карты того же патча. Она сверяет SHA-256, ID, календарь патча и время среза. Пабы, для которых ещё ожидается карточка OpenDota, остаются в журнале. Позже серверный сборщик подхватит их при запуске `refresh_patch_reference.py`. Файл кандидата можно открыть командой `python -m pro_replay school --reference data/next-reference.json`. Команда `--rebuild-packaged` воспроизводит ранее опубликованные модели по исходным 53 пабам и 307 турнирным матчам.

Обычный `train-reference` при пустой папке локальных сборов проверяет версию патча по календарю Valve и использует последний поставленный снимок. При смене патча команда предлагает собрать новые матчи.

Сборщик накапливает наблюдения Live между запусками. Для включения нового паба нужен опубликованный OpenDota числовой средний рейтинг. На новом патче каждая группа набирается заново. Пока в группе мало матчей для временной проверки, тренер показывает только средние и число выступлений.

Если на диске осталась объединённая модель, тренер автоматически выбирает встроенные раздельные модели того же патча, когда их снимок как минимум такой же свежий и включает все локальные матчи в соответствующих группах. Локальный файл сохраняется. Для объединённого файла с дополнительными картами или с явным выбором через `--reference` тренер показывает сохранённые средние подходящей группы. Команда обновления выше переобучает обе модели на локальных выборках и новых наблюдениях.

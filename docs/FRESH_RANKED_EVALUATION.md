# Проверка прогноза экономики на новых матчах 7 300+

## Условия сбора, зафиксированные до расчёта ошибок

17 ноября 2026 года началась проверка опубликованной версии тренера на патче 7.41f. Участники проверки — итоговая модель патча из коммита `bf67208`, предыдущая модель для рейтинговых игр и медианный прирост ресурсов по месту героя среди союзников на 10:00. Все три выдают прогноз по данным до 10:00 включительно. Сравниваем его с полученным золотом, опытом и числом добиваний на 20:00. Веса и настройки зафиксированы. [Версия модели](https://github.com/Asylstyle/pro-replay-lab/commit/bf67208c5888c239fbfd9005c63a2a5da1e5b590)

В выборку входят доступные завершённые игры Ranked All Pick с числовым средним MMR лобби от 7 300 в OpenDota Live. Проверяем патч на момент начала, ID и обе пятёрки героев в итоговой карточке OpenDota. Для каждого из десяти игроков нужны данные на обеих минутах. Матчи из обучения, выбора настроек и прошлых оценок исключаются по ID. Матч, для которого раньше видели только состав и рейтинг лобби, может войти после появления данных об экономике. [Правила отбора](PATCH_REFERENCE.md) · [Источник лобби](https://api.opendota.com/api/live)

Сбор завершается после первого полного обхода, в котором есть 32 новые карты и хотя бы 8 начатых после публикации модели, либо в 20:15 UTC 17 ноября. В обработку идут все подходящие карты этого обхода. Решение об остановке зависит от числа доступных матчей и времени. Для завершённых игр с неполными данными можно запросить стандартный разбор в OpenDota.

## Как читать результаты

Основное сравнение охватывает все новые ID. Две вложенные группы показывают временной порядок строже — сначала только игры, начавшиеся после окончания последней обучающей карты, затем только начавшиеся после публикации модели в 18:26:55 UTC. Размеры этих групп нельзя складывать.

Для каждой модели считаем среднюю абсолютную ошибку на одних и тех же игроках. В разнице «текущая модель минус предыдущая» отрицательное значение означает меньшую ошибку. Для 95%-х интервалов случайно выбираем целые матчи с возвращением, сохраняя обе команды и оба прогноза вместе. Интервалы рассчитываются отдельно для каждого показателя. В разборе по позициям смещение равно прогнозу минус фактическое значение. Положительное смещение означает, что модель в среднем завысила результат.
